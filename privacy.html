Privacy

Kalam has no account, no sign-in, no analytics and no server of its own. What you write is checked on your computer.

The extension

Grammar runs inside the extension. The AI check runs on Kalam for Windows over native messaging (a local pipe between the browser and the app — no network, no open ports) or, without the app, inside the browser. Results are kept in the browser session only.

Kalam for Windows

The app stores model files in %LOCALAPPDATA%\Kalam\models and runs them locally. It goes online only when you download a model or choose “Check for updates”, and then only to this project’s GitHub releases.

Optional runtimes

If you point Kalam at Ollama or LM Studio, requests go to that program on your own computer. Cloud keys stay off unless you add one yourself.

This website

This page is static, hosted by GitHub Pages, with self-hosted fonts and no trackers. GitHub may keep standard server logs.
