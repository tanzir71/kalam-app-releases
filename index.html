What it does

Help on the page you’re already writing.

01

Grammar that never phones home

Spelling, grammar, style and readability run on your machine in milliseconds — even with AI switched off.

02

Rewrite one sentence at a time

Select a sentence, compare a few alternatives, apply the one that sounds like you. Undo is always one click away.

03

An AI-writing signal you can question

Each passage gets its own reading, with the uncertain ones marked. It’s a signal for your own drafts, never a verdict.

04

Lives where you write

A side panel beside any text field, inline fixes as you type, and a shortcut for every other app.

Install steps for an unsigned build
  1. Download the installer and check its SHA-256 (command above) against SHA256SUMS.txt.
  2. Windows SmartScreen shows “Windows protected your PC” for unsigned apps: choose More info → Run anyway once the checksum matches. It installs for your user only — no administrator rights.
  3. Kalam for Windows opens “Connect your browser”: open chrome://extensions or edge://extensions, turn on Developer mode, choose Load unpacked and pick %LOCALAPPDATA%\Kalam\extension.
  4. Open Models in Kalam for Windows and download Kalam Detector 0.3 and the writer. Every file is checked with SHA-256 before use.

Responsible use

A writing tool, not a disguise.

Rewrite suggestions help your own writing read naturally and can reduce false flags on work you wrote. Don’t use them to misrepresent authorship where a school, publisher or employer forbids AI help.

The AI-writing signal can be wrong — especially on short, technical or heavily edited text, and for writers whose first language isn’t English. It is not a probability of authorship. Never use it to judge someone else’s work.
